# Sales Commission Accrual Engine

A synthetic accounting-control demo for commission accruals, capitalization, amortization cohorts, cash payouts, and month-end true-ups.

## Demonstrates
- monthly earned commission accruals
- payout lag
- capitalized commission assets
- cohort amortization schedules
- accrual-to-cash reconciliation
- month-end true-up / exception reporting

This project is intentionally separate from the sales-commission forecasting engine: this repo focuses on **accounting and close mechanics**, while the forecasting engine focuses on plan economics and scenario modeling.

## Run
```bash
pip install -r requirements.txt
streamlit run app.py
```
